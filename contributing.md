# Contributing

Thanks for helping. This list is useful only if it stays accurate and fair, so a few rules.

## What belongs here

- Tools, APIs, standards, guides and templates that help track, limit, allocate or price **AI and LLM costs**.
- The cost feature has to be real and documented. Link to the docs page for it when the main page doesn't show it.
- Vendors may add their own tools. Say so in the pull request.

## How to add an entry

- One pull request per entry, or per correction.
- Put it in the right section, in **alphabetical order**.
- Format: `- [Name](link) - Description.`
  - The description starts with a capital letter and ends with a full stop.
  - Say what the tool does **for cost**, in one line. No marketing words ("best", "leading", "revolutionary").
  - Mention notable limits if you know them (for example, a supported-tools gap).
- Prefer the GitHub link for open-source projects and the product page otherwise.
- Check that every link works.

## Corrections and removals

- If a description is wrong or out of date, open a pull request or an issue with a source.
- Projects that are archived or no longer maintained are removed.

## The maintainers' own product

This list is maintained by the team behind Ganivra. Ganivra entries follow the same rules as every other entry: alphabetical order, one factual line, stated limits. If you think an entry about any tool, Ganivra included, is unfair, open an issue.
